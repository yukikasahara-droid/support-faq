OriHimeの再起動方法について。

OriHimeの再起動は、次の方法で行えます。

1. **OriHimeコントローラー**（遠隔で再起動）
2. **OriHime設定アプリ**
3. **OriHime本体の電源OFFボタン**
4. **本体の電源OFFボタン＋放電**（動作が安定しないとき）

OriHimeが正常に起動しない・動作が安定しない場合は、まず 1〜3 を順にお試しください。それでも改善しない場合は、ACアダプタをコンセントから抜いて放電（内部にたまった電気を放出する操作）を行う 4 をお試しください。

> 「OriHimeコントローラー」からの遠隔再起動は、OriHimeがネットワークに正常接続されている場合に限ります。

## 1. OriHimeコントローラーから再起動する（遠隔）

第7世代・第8世代 共通。操作者が遠隔で再起動できます。

1. OriHimeコントローラーにログインする
2. 電源マークを選択する
3. 「OriHimeを再起動」を選択する

> 電源マークが表示されない場合は、**管理ツール**で操作者の「OriHimeの電源の操作を許可する」にチェックが入っているかご確認ください。

## 2. OriHime設定アプリから再起動する

第7世代・第8世代 共通。

1. OriHime設定アプリにログインする
2. 複数のOriHimeが表示される場合は、再起動したいOriHimeを選択する
3. 電源から「再起動」を選択する

> 電源をOFFにする場合は、手順3で「電源OFF」を選択してください。

## 3. 本体の電源OFFボタンから再起動する

> 電源OFFボタンを連続で押すと故障の原因になります。ご注意ください。

**OriHime第7世代**

| 手順 | 操作方法 | ランプの状態 |
| --- | --- | --- |
| 電源OFF | 本体の電源OFFボタンを押す | 電源OFFボタン横のランプと胸のランプが消灯 |
| 再起動 | 本体の電源OFFボタンを押す | 横のランプが緑点灯 → 胸のランプも緑点灯 |

**OriHime第8世代**

| 手順 | 操作方法 | 胸のランプの状態 |
| --- | --- | --- |
| 電源OFF | 本体の電源OFFボタンを押す | 消灯 |
| 再起動 | 本体の電源OFFボタンを押す | 緑点灯 |

> 第8世代は、付属ケーブルのON/OFFスイッチでの電源操作も可能です。

## 4. 放電を伴う再起動（動作が安定しないとき）

> 電源OFFボタンを連続で押すと故障の原因になります。ご注意ください。

**OriHime第7世代**

| 手順 | 操作方法 |
| --- | --- |
| 電源OFF | 本体の電源OFFボタンを押す（各ランプ消灯） |
| 放電 | ACアダプタをコンセントから抜いて10秒以上待つ |
| 再起動 | ACアダプタをコンセントに挿す（緑点灯） |

**OriHime第8世代**

| 手順 | 操作方法 |
| --- | --- |
| 電源OFF | 本体の電源OFFボタンを押す（消灯） |
| 放電準備 | 付属ケーブルのスイッチをOFF |
| 放電 | ACアダプタをコンセントから抜いて10秒以上待つ |
| 再起動準備 | ACアダプタをコンセントに挿す |
| 再起動 | 付属ケーブルのスイッチをON（緑点灯） |

## 電源OFFボタンの位置とACアダプタ（世代差）

第7世代と第8世代で、電源OFFボタンの位置とケーブル仕様が異なります。

- **第7世代**：電源OFFボタンは本体横。ACアダプタとUSBケーブルが分離しており、電源スイッチはありません。
- **第8世代**：電源OFFボタンは本体背面。ACアダプタとケーブルが一体型で、電源スイッチがあります。
